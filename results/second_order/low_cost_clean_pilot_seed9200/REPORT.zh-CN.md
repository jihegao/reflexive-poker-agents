# 6 人无限注二阶推理低成本 LLM pilot

## 结论

本轮验证了真实 LLM、成对消融、完整 trace 与调用计量链路，但**没有验证二阶策略能稳定提高盈利**。

- `deepseek-v4-flash`：`reflexive_on - reflexive_off = +25 chips/100`，实际只是 6 手中多赢 `1.5 chips`。全部差异来自最后一手，不能视为稳定优势。
- `gpt-5.6-luna`：差异为 `0 chips/100`；两条件的 11 个决策动作与下注尺度完全一致。
- 两个纳入结论的模型运行均为 `0` provider failure、`0` fallback；单 seed 无法估计跨 seed 置信区间。

因此，当前证据最多支持：**DeepSeek 能读取二阶桌面画像并改变价值下注尺度；Luna 在这个 seed 上没有表现出行为变化。二阶信息是否提高 EV 仍未知。**

## 因果处理边界

六个固定席位为 LLM、TAG、LAG、Rock、Calling Station、Myopic control。按钮逐手轮转；每手恢复 100 BB；无抽水；允许持续加注直至筹码耗尽，并正确结算边池。

- `reflexive_off`：只接收底牌、公共牌、位置、合法动作、筹码、底池、多人 equity、pot odds 与公共行动历史。
- `reflexive_on`：额外接收自身公共形象、对手 aggression/fold 汇总、全桌同时弃牌概率与此前逐手复盘。
- 两条件使用相同 seed、牌序、座位和策略 agent 初始化。
- 两条件都会执行复盘调用以保持调用结构可比；只有 on 条件把复盘记忆反馈给后续决策。

这是完整策略效应实验：一旦动作分叉，后续公共历史也会分叉。LLM 采样没有固定随机种子，因此模型采样噪声仍是混杂来源。

## LLM 结果

| Provider/model | off | on | 差值 | 实际筹码差 | 决策/复盘调用 | 失败/回退 |
|---|---:|---:|---:|---:|---:|---:|
| OpenCode Go / deepseek-v4-flash | 91.67 | 116.67 | +25.00 chips/100 | +1.5 | 24 / 12 | 0 / 0 |
| Codex / gpt-5.6-luna | 16.67 | 16.67 | 0.00 chips/100 | 0.0 | 22 / 12 | 0 / 0 |

DeepSeek 的前五手逐手收益在两条件下完全相同：`[0, 0, 0, 0, -1]`。第六手 off 收益 `+6.5`，on 收益 `+8.0`。关键动作同为价值加注，但：

- 转牌：off 为 `0.75 pot`，on 为 `1.0 pot`；
- 河牌：off 为 `0.5 pot`，on 为 `0.6 pot`。

on 的解释明确引用低 aggression、低全桌弃牌概率和 calling-station 桌面画像，说明机制通道被实际使用。不过单手差异也可能来自 LLM 非确定采样，不能单独归因为二阶推理的因果收益。

Luna 两条件从翻前到转牌的动作与尺度逐节点一致，最后均以 `raise_scale=1.25` 全下结束该手，二阶状态只改变了文字解释，没有改变策略输出。

## 调用量与成本

| Provider/model | 总调用 | 总 token | token/调用 | 平均延迟 | on 相对 off token | 报告成本 |
|---|---:|---:|---:|---:|---:|---:|
| OpenCode Go / deepseek-v4-flash | 36 | 513,366 | 14,260 | 16.64 s | +5.3% | $0.070115 |
| Codex / gpt-5.6-luna | 34 | 513,076 | 15,090 | 20.01 s | +3.0% | n/a |

干净证据合计 70 次调用、1,026,442 tokens。OpenCode event 提供美元成本；Codex CLI 只提供 token usage，未提供可换算的本次美元账单。两条链路每次都新建隔离会话，约 12k--15k 固定输入上下文被重复计费，因此 12 个条件-手牌/模型就消耗约 51 万 token。

为定位 provider 与解析问题，本次工程过程还执行了被排除的 DeepSeek runs 和一次 usage 探针：共 73 次额外调用，其中 35 次旧格式调用的 usage 不可观测。被排除部分至少还有 433,807 个已观测 token 和 `$0.056844` OpenCode 报告成本，外加那 35 次未知 usage；这些不计入上面的干净实验结果。包含干净证据在内，本次实际执行共 143 次 LLM 调用，至少观测到 1,460,249 tokens 和 `$0.126959` OpenCode 成本，Codex 成本仍不可得。

## 下一阶段

先做低成本的决策节点 replay，而不是立即拉长完整牌局：抽取 20 个会触发 exploit 的相同公共状态，每个模型、每个条件重复 5 次，比较动作分布和下注尺度，可把 LLM 采样噪声与轨迹分叉分开。

只有 replay 显示稳定行为差异后，再进行确认性轨迹实验：至少 20 个配对 seed、每 seed 12 手，并把模型重复作为第二层随机效应。主指标仍按模型分别计算 paired chips/100；同时报告 cluster bootstrap 区间、正向 seed 比例、单手收益集中度、provider failure/fallback 和 token/cost。任何一侧失败时整对作废并重跑，不能只替换失败条件。

策略对手仍是紧凑启发式 agent，而不是 solver-grade 六人基线；即便确认性结果为正，结论也只适用于此模拟器与该对手生态。
